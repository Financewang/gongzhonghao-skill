# 公众号写作系统 — 消费企业战略观察

> 消费企业战略观察 | 系统化创作工作台

## 这是什么？

这是一套**消费企业战略观察类公众号的完整写作系统**，包含：定位框架、写作风格、研究方法论、选题库、素材库、文稿模板。

## 核心理念

**从碎片化创作到系统化创作**：每次创作都在给系统添砖加瓦，而不是重新发明轮子。

## 如何与 AI 协作

1. 新对话时，发送本仓库链接
2. AI 读取 [SKILL.md](SKILL.md) 即可了解全部上下文
3. 使用指令（如"生成企业研究：伊利股份"）开始协作

## 仓库结构

| 文件夹 | 内容 |
|--------|------|
| `SKILL.md` | AI 协作总纲（最重要的文件） |
| `00-项目指南/` | 写作风格、五维分析框架 |
| `01-内容生产/` | 选题库、素材库、文稿模板 |
| `02-方法论沉淀/` | 写作/选题/研究方法论 |
| `03-数据统计/` | 内容数据、粉丝增长数据 |
| `04-运营方案/` | 完整运营方案 |

## 如何使用（Fork 指南）

1. Fork 本仓库
2. 修改 `SKILL.md` 第一节"关于作者"，填入你自己的背景
3. 根据你的公众号定位，调整 `04-运营方案/完整运营方案.md` 中的主题系列
4. 开始创作
